# content-ops-anindyog

This repository demonstrates Content Operations (ContentOps) ideas. It contains a small DITA XML content library skeleton with sample topics and a DITAMAP to use as a starting point for tooling, transformation, and content workflows.

Structure added:

- README.md — this file
- dita-library/
  - map.ditamap — sample DITAMAP referencing the topics
  - topics/
    - intro.xml
    - concept.xml
    - task.xml
    - reference.xml

Use this as a starting point for demos, CI transformations with DITA-OT, or content automation experiments.
