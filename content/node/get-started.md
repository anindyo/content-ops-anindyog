# Get started with the Node.js library

This section shows how to install the Nano library and use it to connect to an existing Apache CouchDB database.

## Prerequisites

* Install and configure an Apache CouchDB instance.
* Secure your Apache CouchDB instance industry-standard authentication credentials.
* Create databases and documents with 
* Ensure your development environment contains the following dependencies:
  * Node.js v16.20.1 or later
  * Node Package Manager (npm) 10.00.0 or higher

## Download and install

1. Create a Node.js project.
2. To install the library, run the following command:
   ```
   npm install nano
   ```
